# KURT/27 — магазин куртки (в разработке)

## Готово ✅
- Этап 1 — Next.js 15 + TS + Tailwind v4, тёмная тема, layout в стиле Adidas
- Этап 2 — плавный скролл Lenis + GSAP-появление
- Этап 3 — 3D-сцена: трек-куртка на вешалке, неон, туман, отражающий пол (React Three Fiber)
- Этап 4 — рейл с вешалками (стиль Hookline): клик → куртка выдвигается,
  панель с ценой, размерами, кнопкой «В корзину», фильтры

## Запуск (на ПК)
```bash
npm install
npm run dev
```
http://localhost:3000
